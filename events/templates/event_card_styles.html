{% comment %} Included in the meta block of every page that shows event avatars (event_list.html, event_detail.html, encyclopedia plant_detail.html). Attendee avatars on the event cards (Figma "Event Card"). They're classes here instead of Tailwind classes in the HTML because event_rsvp.js draws new avatars after an RSVP, and the Tailwind CDN only builds styles for classes it has already seen on the page. These are ready from the start, so a new avatar never shows up unstyled. @source inline(...) does the same for the 4 avatar colors (accounts AVATAR_BG_CLASSES) and object-cover for photos. {% endcomment %}
